# PBL Phase-I — Instructions for Report & PPT Creation

## 1. Mandatory Tooling

- **LaTeX is mandatory** for both the Phase-I Report and the Phase-I Presentation (PPT). No Word/Google Docs/Canva substitutes.
- **Platform:** [Overleaf](https://www.overleaf.com/) must be used to prepare both documents.
- **Tutorial:** [LaTeX Tutorial Video](https://youtu.be/_PzDLFJHO3E?si=m8Lr25UyQgCrNQyv) — watch before starting if unfamiliar with LaTeX.
- **Templates:** Use only the prescribed LaTeX templates from `PBL_Phase-1_Format.zip` (department-attached) — cross-check against your local `sample/` folder for the exact report and PPT format files, and use those as the base `.tex` project in Overleaf rather than building from scratch.

## 2. Format Compliance (Strict)

- Follow the **prescribed Report and Presentation formats exactly** as provided on the PBL Portal / in `PBL_Phase-1_Format.zip`. Do not modify section order, headings, or structure without mentor approval.
- Do not deviate from the template's fonts, margins, title page layout, or section numbering.
- Submitted reports go through **Departmental Review Committee** evaluation — check the portal regularly for feedback and **incorporate every suggested correction** into your Phase-I presentation.

## 3. Required Content (Report + PPT)

Both the report and the presentation must clearly cover:

1. **Project title** — finalized in consultation with your mentor.
2. **Problem statement** and project objectives.
3. **Proposed solution** and system architecture.
4. **Subject integration** — how the PBL-linked subjects tie into the project.
5. **Initial progress** achieved so far.
6. **Individual technical contribution** for each team member.
7. **Planned milestones** and expected outcomes.

## 4. Academic Integrity

- Strictly comply with the **Departmental Plagiarism Policy and Academic Integrity Guidelines** while preparing the report and PPT content.
- Originality is an explicit evaluation criterion — do not copy structure, text, or diagrams from other teams' work or external sources without proper attribution.

---

### Report & PPT Checklist
- [ ] Project title finalized and mentor-approved
- [ ] Report written in LaTeX using the prescribed template (from `sample/` folder / `PBL_Phase-1_Format.zip`)
- [ ] PPT written in LaTeX (Beamer) using the prescribed template
- [ ] All 7 required content points covered in both report and PPT
- [ ] Each member's individual contribution clearly documented
- [ ] Plagiarism policy reviewed and followed
- [ ] Portal checked for Departmental Review Committee feedback, and corrections applied
